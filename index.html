PaperTriage

批量扫描

递归扫描论文 PDF，自动生成可检索的 CSV 和 Markdown 文献索引。

智能线索

提取 DOI、年份、标题候选和文件哈希，快速发现重复下载的论文。

安全重命名

默认 dry-run，不改原文件；确认后只创建规范命名的 PDF 副本。

适合谁

  • 下载了大量论文，文件名混乱，想快速整理阅读库的研究生。
  • 需要把 PDF 文献列表导入 Excel、WPS、Obsidian 或 Notion 的论文作者。
  • 需要在不上传论文、不泄露数据的情况下本地处理文献文件的人。

交付文件

工具包包含 papertriage.py、papertriage_gui.py、Windows 双击启动脚本、使用说明和授权文件。只需要 Python 3 即可运行；如果安装 PyMuPDF 或 pypdf，PDF 文本提取效果会更好。
